# JA Capital

Четыре AI-агента торгуют криптой на **реальных котировках**:

- **Леон** следит за трендами шести монет и читает новости CoinDesk, The Block, Decrypt и Cointelegraph;
- **Генри** оценивает риск каждой идеи, считает стоп, тейк и размер позиции;
- **Марк** превращает сводку и риск в сигнал с уверенностью в процентах;
- **Диана** открывает и закрывает сделки, переносит стоп в безубыток, соблюдает дневной лимит убытка.

Агенты работают на сервере круглосуточно, даже когда страница закрыта. Браузер показывает офис с человечками, ленту переговоров, портфель и графики.

## Режимы

| Режим | Что происходит | Что нужно |
|---|---|---|
| `TRADING_MODE=paper` | Цены и новости настоящие, счёт виртуальный ($10 000). | Ничего, кроме пароля |
| `TRADING_MODE=exchange` + `EXCHANGE_ENV=demo` | Ордера уходят на **демо-счёт** биржи, который торгует по реальным ценам. | Ключи API демо-счёта |
| `TRADING_MODE=exchange` + `EXCHANGE_ENV=testnet` | Ордера уходят в **тестовую сеть** Bybit. Цены там свои и отличаются от реальных. | Ключи API тестовой сети |

Торговля реальными деньгами в этой версии выключена: сервер не запустится, если `EXCHANGE_ENV` не `demo` и не `testnet`.

Поддерживаются **Bybit** (`EXCHANGE=bybit`) и **Binance** (`EXCHANGE=binance`). Для фьючерсов Binance подходит только демо-торговля, старой тестовой сети фьючерсов у Binance больше нет. `MARKET_TYPE=swap` — бессрочные фьючерсы USDT (можно шортить), `spot` — только покупки.

### Ключи демо-счёта

- **Bybit:** войдите в аккаунт, переключитесь в режим демо-торговли и создайте ключ API уже там. Ключ основного счёта не подойдёт.
- **Bybit testnet:** зарегистрируйтесь на testnet.bybit.com, пополните тестовый счёт и создайте ключ там.
- **Binance:** ключ создаётся в режиме демо-торговли Binance.

Ключу нужны права на чтение и торговлю. Права на вывод средств **не включайте**.

## Запуск на своём компьютере

Нужен Node.js 18.17 или новее.

```bash
npm install
cp .env.example .env      # задайте ACCESS_PASSWORD и, если нужно, ключи
npm start
```

Откройте http://localhost:3000 и введите пароль.

Проверка без интернета и ключей, на имитации биржи (пароль `demo`):

```bash
npm run mock
```

## Запуск на Render

1. Загрузите папку в репозиторий GitHub.
2. В Render: **New → Blueprint**, выберите репозиторий. Настройки возьмутся из `render.yaml`.
3. Задайте секреты: `ACCESS_PASSWORD`, при необходимости `EXCHANGE_API_KEY`, `EXCHANGE_API_SECRET` и `ANTHROPIC_API_KEY`.

Важно:

- **Регион** — Франкфурт (уже указан в `render.yaml`). Биржи блокируют запросы с американских серверов (ошибка 451).
- **Бесплатный план засыпает** через 15 минут без посетителей, и агенты перестают торговать. Для круглосуточной работы нужен платный план (в `render.yaml` указан `starter`) с диском для сохранения состояния.

## Структура

- `server.js` — веб-сервер, вход по паролю, WebSocket, расписание опросов.
- `src/` — котировки (`market.js`), новости (`news.js`), логика агентов (`brain.js`), исполнение ордеров (`broker.js`), офис и сделки (`office.js`), Claude (`claude.js`).
- `client/` — исходники интерфейса. После правок соберите `public/index.html` командой `python3 build.py`.

## Claude

Если задан `ANTHROPIC_API_KEY` (ключ Claude API с console.anthropic.com, оплачивается отдельно от подписки Claude):

- Леон разбирает заголовки новостей через Claude: какие монеты затронуты, какой тон, насколько это важно, перевод на русский;
- работает **планёрка** и **разговор с любым агентом**.

Без ключа новости разбираются словарём, а планёрка и разговор выключены. Число обращений к Claude ограничено: 40 разговоров, 8 планёрок и 30 разборов новостей в час.

## Как устроена торговля

- Котировки обновляются каждые `TICKER_SECONDS`, свечи — `TIMEFRAME` (по умолчанию 5 минут).
- Сводка Леона — каждые `SCAN_SECONDS` и сразу после важной новости.
- Генри рискует `riskPct`% капитала на сделку и ограничивает один ордер суммой `MAX_ORDER_USD`.
- **Стопы и тейки виртуальные:** их отслеживает сервер и закрывает позицию рыночным ордером. Если сервер выключен, позиции на бирже ничем не защищены.
- Каждые 5 минут Диана сверяет фьючерсные позиции с биржей. Позицию, которую закрыли вручную на бирже, она убирает из учёта. Позицию, открытую на бирже без неё (например, после перезапуска с чистым диском), берёт под контроль со своим стопом и тейком.
- Профиль риска, порог сигналов, лимиты, ручное подтверждение сделок и паузу торговли можно менять прямо в интерфейсе.
